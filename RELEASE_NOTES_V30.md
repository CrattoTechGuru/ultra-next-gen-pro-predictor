# CRATTO CTRL v30.0 — Intelligence Core

## Major layers
1. Historical-data coverage and quality analysis.
2. Poisson goal model.
3. Dixon-Coles-style low-score adjustment.
4. Dynamic Elo strength model.
5. Recent-form model.
6. Adaptive weighted ensemble.
7. Walk-forward evaluation.
8. Probability calibration bins.
9. Competition-level performance analysis.
10. Intelligence API endpoints for model inspection and prediction.

## Endpoints
- GET /api/intelligence/overview
- GET /api/intelligence/backtest
- GET /api/intelligence/calibration
- GET /api/intelligence/leagues
- GET /api/intelligence/coverage
- POST /api/intelligence/predict

## Important
The system reports statistical estimates and historical evaluation. It does not guarantee match outcomes, 98% accuracy, or profit. Odds/value calculations require actual odds supplied by an approved source.
