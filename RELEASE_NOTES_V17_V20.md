# CRATTO CTRL V17–V20 Release

## V17 — Operations Automation
- Scheduled historical fixture synchronization.
- Scheduled upcoming fixture/prediction refresh.
- Manual admin-triggered operations run.
- Operations status and job history.
- Configurable `SYNC_INTERVAL_MINUTES` (default 30).

## V18 — Model Lab
- Persistent model registry in PostgreSQL.
- Model version/status/metrics records.
- Core model registration on startup.
- Model registry endpoint and dashboard.

## V19 — User Operations
- Persistent notification table.
- User notification list/read endpoints.
- Audit-event hooks for sensitive user actions.
- Account-level operational visibility.

## V20 — Platform & Security
- API rate limiting.
- Platform health endpoint.
- Usage telemetry.
- Bookmaker-ready export target for BETWAY and HOLLYWOODBETS.
- Explicit protection against fabricating official bookmaker booking codes.
- Production database migration additions.

## Environment variables
- `FOOTBALL_DATA_API_KEY`
- `DATABASE_URL`
- `DATABASE_SSL` (normally `false` for Render internal DB URL)
- `ADMIN_KEY`
- `NODE_ENV=production`
- `SYNC_INTERVAL_MINUTES` (optional; default `30`)

## Important
CRATTO CTRL can prepare bookmaker-ready selections, but official Betway/Hollywoodbets booking codes must be generated by the respective bookmaker platform.
